# Projekti_majaslapas

Demo websites for local businesses in Jelgava. Plain HTML/CSS/JS, no build step.

## How to look at a demo

Easiest: open **`preview/<demo>/`** on GitHub, download the single `*-demo.html` file
(click it → "Download raw file") and open it in Chrome or Safari. Everything is inside that one file.

Or watch the `.mp4` recordings in the same folder.

| Demo | Page source | Preview | Languages |
|------|-------------|---------|-----------|
| Clementine (café) | `demos/clementine/` | `preview/clementine/clementine-demo.html` | LV / EN |
| Kafe-Picērija (pizzeria) | `demos/kafe-picerija/` | `preview/kafe-picerija/picerija-demo.html` | LV / RU |
| Lotes Spots (family café) | `demos/lotes-spots/` | `preview/lotes-spots/lotes-spots-demo.html` | LV |
| SKY BEAUTY (beauty salon) | `demos/sky-beauty/` | `preview/sky-beauty/sky-beauty-demo.html` | LV / RU |

To open the full source version instead: GitHub → **Code → Download ZIP**, unzip, open `demos/<demo>/index.html`.

## Notes

- These are concepts built from each business's public information and photos. Not official sites, not published.
- Booking/order forms don't send anything.
- `.claude/skills/` holds the design and animation skills used to build them.
