# kagus.eu reel (Latvian, 18 s, 1080×1920)

- `kagus-reel.mp4`: the reel, 30 fps, no sound. Add music in Instagram.
- `cover.jpg`: cover frame (the outro with the logo).
- `reel.html`: the animation. Open it in a browser to watch it loop.
- `render.mjs`: renders it frame by frame. Run `node marketing/kagus-reel/render.mjs <frames-dir> marketing/kagus-reel/kagus-reel.mp4`.
- `assets/`: logo and Geist fonts, taken from kagus.eu.
